# 지금갈래? — Incheon Field Agent

> 인천에서는 갈 곳이 없어서가 아니라, 지금 내 시간과 동선에 맞는 곳을 고르기 어려웠습니다.
> `지금갈래?`는 현장 관찰과 실시간 조건을 바탕으로, 지금 출발할 한 곳을 결정해주는 Agent입니다.

인천 토박이 지인한테 전화 걸어 "나 인천역 근처인데 코스 좀 짜줘" 하는 경험을 웹으로 옮긴 프로토타입입니다.

**핵심 질문** — "지금 이 자리에서 90분 안에 갈 수 있고, 내 상황에 맞는 인천의 장소는 어디지?"

## 동작 방식

```
브라우저 (위치·시간·이동수단·목적·메모)
   │
   ├─ POST /api/recommend ──┐
   │                        │  1. 좌표로 이동시간 계산 → 시간 예산 안에 드는 곳만 필터
   │                        │  2. 도착 시각 기준 영업 상태 확인 (휴관일·마감 임박)
   │                        │  3. Open-Meteo로 현재 강수 확인 → 비 오면 실내 가산
   │                        │  4. 상위 5곳을 RunYourAI 라우터에 넘겨 순위·문구만 위임
   │                        │  5. 반환된 id를 화이트리스트로 검증
   │                        └─ 실패/타임아웃/키 없음 → 3번까지의 결정론적 결과
   │
   └─ /api 자체가 없으면 (GitHub Pages) 같은 로직을 브라우저에서 실행
```

**장소를 모델이 생성하게 하지 않습니다.** 후보 집합은 서버가 고정하고, 라우터는 순위 결정과
추천 문구 작성만 합니다. 반환된 id가 후보 밖이면 전부 버리고 결정론적 결과로 떨어집니다.
존재하지 않는 가게와 깨진 지도 링크가 나오는 것이 이 제품에서 가장 치명적인 실패이기 때문입니다.

덕분에 네트워크가 끊긴 발표장에서도, API 키가 없어도 앱은 그대로 동작합니다.

## 구조

| 경로 | 역할 |
| --- | --- |
| `index.html`, `styles.css`, `app.js` | 정적 프런트엔드. 모듈 스크립트, 빌드 없음 |
| `lib/places.js` | 장소 데이터 (좌표·목적 태그·체류시간·영업시간·실내 여부) |
| `lib/recommend.js` | 순수 추천 로직. 브라우저와 서버가 **같은 코드**를 쓴다 |
| `api/recommend.js` | Vercel 서버리스 함수. 날씨 조회 + RunYourAI 라우터 호출 + 출력 검증 |
| `test/recommend.test.js` | `node:test` 기반 테스트 (네트워크 없이 실행) |

## 실행

```bash
# 프런트엔드만 (라우터 없이 로컬 추천으로 동작)
python3 -m http.server 8000

# 서버리스 함수까지
cp .env.example .env.local   # 값 채우기
npx vercel dev

npm test
```

## RunYourAI 라우터 연결

[RunYourAI](https://www.runyour.ai/)의 [Runyour Agent](https://agent.runyour.ai/)는 API Key 하나로
여러 LLM을 호출하는 게이트웨이입니다. 토큰 종량제이고 조직·개인 단위 예산 상한을 걸 수 있습니다.

`.env.example`의 세 값을 채우면 라우터를 사용하고, 하나라도 비면 로컬 추천으로 동작합니다.

> ⚠️ 이 코드를 작성한 시점에 라우터의 공개 개발자 문서를 찾지 못해,
> `api/recommend.js`는 **OpenAI 호환 `POST {BASE_URL}/chat/completions` + `Authorization: Bearer`** 를 가정합니다.
> 콘솔에서 실제 스펙을 확인한 뒤 `routeWithRunYourAI()`의 요청/응답 파싱만 맞추면 됩니다.
> 그 외 코드는 라우터 스펙에 의존하지 않습니다.

**API 키는 절대 프런트엔드에 넣지 마세요.** 정적 페이지에 박은 키는 devtools를 여는 누구나
꺼내 쓸 수 있고, 그대로 토큰 예산이 됩니다. 서버리스 함수를 두는 이유가 이것입니다.

현재 `/api/recommend`에는 인증도 레이트리밋도 없습니다. 해커톤 데모 범위에서는 괜찮지만
공개 배포 시에는 호출 상한(IP별 제한, Vercel 상의 KV 카운터 등)을 먼저 붙이세요.

## 알려진 한계

- **이동시간은 추정치입니다.** 직선거리 × 1.3에 이동수단별 평균 속도를 적용합니다
  (`lib/recommend.js`의 `estimateTravelMin`). 실제 경로 API로 교체할 수 있는 단일 지점으로 분리해 뒀습니다.
- **좌표는 대표 지점 근사값, 영업시간은 데모용 기본값입니다.** 실제 서비스 전에
  현장 확인이나 공공데이터로 교체해야 합니다. 틀린 영업시간은 사용자를 헛걸음시킵니다.
- 현장 메모는 라우터를 거칠 때만 추천에 반영됩니다. 로컬 폴백에서는 그 사실을 화면에 표시합니다.
- 사용자가 남긴 메모는 제3자 LLM 게이트웨이로 전송됩니다. 공개 서비스로 전환한다면 고지가 필요합니다.
