# 지금갈래? — Incheon Field Agent

인천 현장에서 남긴 메모와 사용자의 시간·이동수단·목적을 바탕으로, **지금 출발할 한 곳**을 제안하는 모바일 우선 정적 웹 프로토타입입니다.

## 핵심 흐름
1. 남은 시간과 이동수단, 원하는 활동을 고른다.
2. 현장 관찰 메모를 선택적으로 남긴다.
3. Agent가 로컬 큐레이션 데이터로 장소 3곳을 정리하고 최우선 장소를 제안한다.
4. 네이버 지도 검색 링크로 바로 출발한다.

## 실행
별도 의존성이 없습니다. `index.html`을 브라우저에서 열거나 다음 명령으로 로컬 서버를 실행하세요.

```bash
python3 -m http.server 8000
```

이후 <http://localhost:8000>에서 확인합니다.

> 해커톤 데모에서는 `app.js`의 예시 장소 데이터와 현장 메모를 실제 관찰 결과로 교체하면 됩니다.
